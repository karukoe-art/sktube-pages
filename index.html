Fire TV向け YouTubeクライアント

テレビのリモコンで、動画をもっと手軽に。

SKTubeは、Fire TV向けに開発された非公式のAndroidアプリです。リモコン操作に合わせた画面から、動画の検索・視聴ができます。

開発中のアプリです

Fire TVで更新を確認した開発版は v0.3.13 です。端末・動画・認証環境によって一部機能が利用できない場合があります。配布および動作保証を案内するページではありません。

主な機能

📺 リモコンで操作

十字キーと決定キーでホーム画面・動画一覧・プレイヤーを操作できます。

🔎 動画を探す

動画検索、日本の人気動画、端末内履歴に基づく関連検索を利用できます（設定が必要な機能があります）。

📁 登録チャンネル

Googleアカウント連携時に登録済みチャンネルと、その公開動画を確認できます。

⏯ 続きから見る

SKTube内での再生位置を端末に記録し、同じ動画を開くと続きから再生する機能を備えています。

⚡ 再生速度

利用可能な再生速度を変更し、SKTubeで選択した速度を端末内に記憶します。

🕘 履歴

SKTubeで開いた動画を端末内履歴から探せます。履歴はアプリ内から削除できます。

Googleアカウントとの連携

連携は任意です。登録チャンネル情報を取得するため、Googleのテレビ向け認可フローを使用します。YouTubeの読み取り専用権限を要求し、登録チャンネルの表示などに利用します。v0.3.13では再生画面からチャンネル登録ができます。未登録チャンネルを登録する際は、同じYouTubeチャンネルで追加のGoogle権限を承認する必要があります。公式YouTubeで登録する選択肢も用意しています。

利用しているサービス

YouTube IFrame Player API・YouTube Data API v3・Google OAuth 2.0 を利用します。YouTube公式のホーム画面やおすすめアルゴリズムを再現するものではありません。広告を削除する機能は説明しておらず、YouTube公式プレイヤーを改変しません。

プライバシーポリシーを確認する

SKTube — 個人開発の非公式アプリ。YouTubeおよびGoogleの公式製品ではありません。
